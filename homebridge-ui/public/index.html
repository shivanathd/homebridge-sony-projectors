Connect your Sony projector

Enter the projector's address and its web administrator password. The plugin detects the model and control protocol automatically.

Before connecting, on the projector:
  • Set Installation > Remote Start (or Network Management) to On so it can be turned on over the network.
  • Make sure ADCP (or PJ Talk on older models) is enabled in its network settings.
  • Give it a fixed IP address with a DHCP reservation on your router.

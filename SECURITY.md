# Security policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/shivanathd/homebridge-sony-projectors/security/advisories/new). Do not open a public issue.

You can expect an acknowledgement within a week. Fixes are released as soon as practical and credited in the changelog unless you prefer otherwise.

## Scope

In scope: the plugin's code, its settings UI, and how it handles credentials and data sent to projectors.

Out of scope: weaknesses in Sony's protocols themselves (for example, SDCP having no real authentication). These are documented in
[docs/Security.md](docs/Security.md) along with recommended mitigations.

## Supported versions

Only the latest release receives security fixes.

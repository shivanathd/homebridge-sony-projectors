# Feature Options

Feature options turn optional HomeKit features on or off, globally or for one projector. The easiest way to set them is the **Feature Options** tab in the
plugin's settings in the Homebridge UI.

In `config.json` they are strings in the platform's `options` array:

| Form | Meaning |
|---|---|
| `Enable.Picture.Switches` | Turn a feature on for every projector. |
| `Disable.Remote` | Turn a feature off for every projector. |
| `Enable.Picture.Switches.192-168-1-50` | Turn a feature on for one projector. The suffix is the projector's host with `.` and `:` replaced by `-`. |
| `Enable.Remote.PlayPause=menu` | Set a value option. |

A projector-specific option always wins over a global one.
